# Why did the chicken cross the road?

mi23011 - Nikola Lazic  
A nighttime scene with a road in a forest and two chickens ready to cross!
Try the flashlight, customizable lamp colors and vignette effect toggle!

## Controls

| Control | Action                                        |
|---------|-----------------------------------------------|
| W/A/S/D | Move the camera                               |
| Mouse   | Look around                                   |
| F2      | Toggle the GUI                                |
| C       | Trigger the warning and hen crossing sequence |
| F       | Toggle the camera flashlight                  |
| P       | Toggle vignette post-processing               |
| Escape  | Close the program                             |

The GUI controls the normal lamp color, warning lamp color, flashlight strength, and vignette strength.

## Features

### Fundamental:

[X] Model with lighting
[X] Two types of lighting with customizable colors and movement through GUI or ACTIONS
[X] Press C ---> lamps turn off --- AFTER 0.5 SECONDS ---> warning lights activate and the hens cross --- AFTER 3
SECONDS ---> lamps turn off and the hens turn around --- AFTER 0.5 SECONDS ---> normal lighting returns

### Group A:

[X] Frame-buffers with post-processing   
[ ] Off-screen Anti-Aliasing  
[ ] Parallax Mapping
[ ] Bloom with the use of HDR

### Group B:

[ ] Deferred Shading  
[ ] Point Shadows  
[ ] SSAO

### Engine improvement:

Nothing
